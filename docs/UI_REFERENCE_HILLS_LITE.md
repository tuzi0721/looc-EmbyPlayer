# Hills Lite UI 参考规格（来自用户截图 2026-05-25）

> **原则**：先 1:1 复刻参考播放器 UI/交互，再改 Emby 特有细节。  
> **导航**：返回必须逐级——播放页 → 详情页 → 上一级，**禁止**播放页一键回首页。

---

## 全局布局

| 区域 | 规格 |
|---|---|
| 主题 | 深色 `#121212` / `#1e1e1e`，白字，**紫色强调**（按钮、进度条、选中边框） |
| 结构 | 左 Sidebar（固定宽）+ 右主内容 |
| 顶栏 | 居中圆角搜索框「搜索」；Windows 窗口按钮右上 |
| Sidebar 顶 | ☰ + 「Hills Lite」 |

### Sidebar 导航（自上而下）

1. **首页**（home 图标）
2. **收藏**（heart）
3. **聚合视界**（∞）
4. **服务器**（标题 + 右侧小齿轮）
   - 服务器项：绿色播放图标 + 名称 + 副标题（昨天看过/今天看过）+ 右侧 `-` 移除
5. **Hills Lite Pro**（crown）— 参考 UI 有，先做占位/入口
6. **＋ 添加服务器**
7. **设置**（gear）— 选中时高亮底

## 图5 — 详情页 `/item/:id`

### Hero
- 背景图 cover + 底部渐变
- 左上英文/主视觉 logo（可选）
- **继续播放**：大紫色圆角按钮 + 播放图标
- 圆形操作：**分享 · 收藏(♥) · 已看(✓)**
- 标题 + `S1:E1 - …`
- 元数据行：★ · 日期 · 时长 · 类型标签
- 简介

### 右下三下拉（半透明底）
- **版本**：WEB-DL / 1080p / H264 / 码率
- **音频**：Japanese AAC stereo (默认)
- **字幕**：Chinese Simplified (默认 SUBRIP)

### 剧集区
- 「更多来自 第 N 季」+ 下拉 + 右侧查看全部
- 横滑集数缩略图，**当前集紫色边框**
- 缩略图下集标题

### 演职人员
- 标题「演职人员」+ 横滑头像（可先空框架）

## 图2/3 — 播放页 `/player/:id`

### 布局
- 全屏视频（MPV 窗口/嵌入）
- 半透明 overlay 控件

### 左上/底部信息
- 大标题 + `S1:E1 - …`
- 进度条：**紫色**已播放 + 圆形 thumb
- 左时间 / 右总时长

### 底栏控件（左→右，用户确认 2026-05-25）

**左侧（ transport ）**：上一集 · 播放/暂停 · 下一集 · 音量

**右侧（从左到右）**：

| 顺序 | 控件 | 说明 |
|---|---|---|
| 1 | 倍速 | `1.0x` |
| 2 | 版本 | 场记板图标 — **片源/版本切换** |
| 3 | 音轨 | 音符 |
| 4 | 字幕 | CC |
| 5 | 弹幕 | 弹幕开关/设置入口 |
| 6 | 设置 | 齿轮 → 弹出菜单（缩放/Anime4K/跳过/字幕/弹幕/统计） |
| 7 | 选集 | 三横+箭头 — **选集列表** |
| 8 | 全屏 | 四角括号 |

### 右上
| 元素 | 说明 |
|---|---|
| 网速 MB/s + 折线 | **设置里加开关**，用户开启后才显示 |
| 图钉 | sticky on top（参考有，具体行为待定，可先占位） |
| 窗口按钮 | 最小化 / 最大化 / 关闭 |

### 设置菜单（齿轮弹出）
- 设置
- 缩放模式 >
- Anime4K [PRO] >
- 跳过片头/片尾 [PRO] 开关
- 字幕设置
- 弹幕设置
- 统计信息

### 字幕
- 底部居中白字 + 描边

### 右上（图2）
- 网速 MB/s + 折线图
- 置顶图钉
- 窗口控制

### 返回
