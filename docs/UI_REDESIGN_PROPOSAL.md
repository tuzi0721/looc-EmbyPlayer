# Hills Lite UI / 主题改造设计方案（v1，待评审）

> 目的：解决「白色主题与巨幕海报配合差、详情页布局弱」的问题，对齐主流影音客户端的观感。
> 本文档为**方案稿**，确认后再实现。每条均标注「为什么 / 怎么做 / 改哪里」。

## 0. 调研结论（主流做法）

- 主流影音 UI（Plex Modern、Apple TV、Jellyfin 主题 ijelly / Abyss / NetFin / Finity）**几乎一律深色影院风**，让**艺术图/海报当主角**；纯白主题做海报墙普遍观感差 —— 与你的体感一致。
- Plex「Modern」关键范式：详情页**优先用宽幅 backdrop**（而非海报）、**从艺术图提取主色**做沉浸背景、**顶部内联元数据**（类型/评分/时长/简介）、**不在海报下重复标题**（标题常已在海报里）、hero 不吃满整屏（露出下一行）。
- Jellyfin 主流主题共性：**玻璃拟态**（frosted glass）面板/弹窗、**弹性动效**（spring/cubic-bezier，错落淡入）、**元数据胶囊**、**圆角卡片 + hover 抬升/缩放**、统一间距与排版。

## 1. 方向与原则

1. **深色影院风为默认与主打**。白色主题保留为可选，但重做为「柔和日光」而非刺眼纯白（让海报仍能跳出）；不再把纯白当海报墙底。
2. **艺术图是主角**：home hero 与详情页都以 backdrop 巨幕为核心，文字/控件叠加在渐变蒙版上。
3. **沉浸氛围色**：从当前条目 backdrop 提取主色，作为 hero/详情页的氛围光（径向渐变 + 顶栏微染），切换条目时平滑过渡。（进阶项，可二期）
4. **克制与一致**：统一 4/8px 间距阶、统一圆角、统一区块标题、统一卡片 hover。
5. **动效有节制**：复用现有 `--easing-spring`，列表错落淡入、卡片 hover 抬升、心形/按钮微弹。

## 2. 配色系统（tokens 调整，改 `src/styles/theme.css`）

### 深色（默认）
- 基底更纯净：`--bg-base: #0b0b0f`；分层表面 `--surface-1:#141418 / --surface-2:#1c1c22 / --surface-3:#26262e`。
- 文本对比微调：主 `rgba(255,255,255,.95)`、次 `.66`、三 `.45`。
- 强调色：保留紫，但**收敛为单一主强调** `--accent:#a855f7`（hover `#c084fc`）。新增**氛围色变量** `--ambient: <从backdrop提取>`（默认回退到 accent）。
- 玻璃：`--glass-bg: rgba(20,20,26,.6)`、`--glass-border: rgba(255,255,255,.10)`、统一 `--glass-blur:20px`（Windows 仍按现有规则关 backdrop-filter，用不透明回退）。

### 浅色（重做为「柔和日光」）
- 不用纯白画布：`--bg-base:#e9edf3`，表面 `#ffffff/#f2f5fa/#e6ebf2`，给海报留对比。
- 文本 `#0f172a / #33415a / #64748b`；强调紫 `#7c3aed`。
- hero/详情页在浅色下用**深色蒙版**压住 backdrop，保证标题/胶囊可读（关键：浅色下也用深底 hero，海报区局部深色化）。

### 间距 / 圆角 / 阴影阶
- 间距阶：`4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 圆角：卡片/面板 `--r-card:14px`、大面板 `--r-lg:20px`、胶囊 `999px`。
- 阴影：卡片 hover `0 14px 40px rgba(0,0,0,.5)`（浅色降透明度）。

## 3. Home Hero / 聚光 Banner（改 `components/common/HeroCarousel.vue` + `views/HomeView.vue`）

- 采用 **Spotlight Banner**：全宽 backdrop（固定影院比例，已有 8:3 基础），底部强渐变融入页面底色；左侧叠加：标题（有 logo art 用 logo）、**元数据胶囊行**（年份·评分·时长·清晰度/编码）、一行简介、主按钮「播放/继续观看」+ 次按钮（收藏/详情）。
- hero **不吃满屏**：保证下方「继续观看/媒体库」首行露出（已修过比例，沿用并收紧）。
- 多条目轮播：底部小圆点 + 自动轮播 + hover 暂停。

## 4. 详情页（重排 `views/DetailView.vue`）

桌面布局（宽度 >= 1024）：
1. 顶部 **backdrop 巨幕**（优先 backdrop，缺失才用海报放大），高度约 `clamp(360px, 46vh, 560px)`，底部渐变融入。
2. backdrop 之上/下缘叠加 **inline 元数据区**：标题（或 logo art）+ 胶囊行（年份·评分·时长·分级·编码/清晰度）+ 简短简介（2~3 行，省略）。
3. **主行动区**：大「播放/继续」+ 次按钮（收藏、标记已看、下载、线路/版本选择、更多）。
4. 其下分区（统一区块标题 + 横向滚动行）：演职人员（圆/圆角头像 + 姓名/角色）、剧集（季选择 + 集卡片）、相似推荐、特典。
5. 氛围背景：整页底用从 backdrop 提取的氛围色径向渐变（二期）。

窄屏（<1024）：backdrop 顶部 → 海报 + 标题胶囊纵向 → 行动区 → 分区。避免现有「小窗压扁/命中区」问题（沿用已修的 hero 命中修复）。

## 5. 卡片 / 海报（`components/common/PosterCard.vue`）

- 圆角 `--r-card`，hover：抬升 + 1.04 缩放 + 阴影 + 渐显标题/进度。
- 进度条（继续观看）压在底部。
- 骨架屏加载（已有 Skeleton 复用）。
- Modern 取向：海报下默认**不重复标题**（标题在 hero/inline），列表网格保留标题（可配置）。

## 6. 导航 / 框架（`components/common/AppSidebar.vue` / `TopBar.vue`）

- 侧栏玻璃化 + 选中态用 accent 软底 + 左侧高亮条/胶囊；图标 + 文案对齐。
- 顶栏：搜索 + 账号/通知；窗口控制（最小/最大/还原/关闭）作为单独项（与播放器窗口控制需求合并到一期或二期）。

## 7. 动效

- 复用 `--easing-spring`；进入页面区块错落淡入（stagger 40ms）；卡片 hover spring；心形点赞微弹；hero 切换交叉淡入 + 氛围色过渡。

## 8. 分期实施计划（建议顺序）

- **一期（基础观感，风险低）**：① tokens 重订（深色为默认、浅色改柔和日光、间距/圆角/阴影阶）；② 卡片/海报 hover 与圆角统一；③ 侧栏/顶栏选中态与玻璃统一。
- **二期（核心信息架构）**：④ Home Spotlight Banner（元数据胶囊+行动区）；⑤ 详情页重排（backdrop 优先 + inline 元数据 + 行动区 + 分区）。
- **三期（沉浸进阶）**：⑥ backdrop 主色提取氛围背景 + 切换过渡；⑦ 动效打磨（stagger / spring 细节）。
- **四期（与播放器收尾）**：⑧ 顶部正常窗口控制（最小/最大/还原/关闭）；⑨ 播放器 OSD 视觉与全局语言统一。

## 9. 待你确认的取舍

- A. **默认主题**：建议「深色为默认主打、浅色重做为柔和日光」。是否同意？（或：只做深色，砍掉浅色）
- B. **氛围主色提取**（Plex Modern 同款）：要不要做（二期/三期）？需要前端取色（canvas 采样 backdrop）。
- C. **详情页**：backdrop 优先（Modern）还是海报优先（Classic）？建议 Modern。
- D. **实施顺序**：是否按上面一→四期推进。
