# 2026-05-29 02:32 - 详情页类型与剧集进度

## 本段目标
- 把详情页的媒体类型从普通文本标签提升为可识别的类型徽标。
- 让剧集缩略图直接显示集数、播放进度和已看状态。

## 变更
- 详情页 Hero 新增媒体类型徽标，按电影、剧集、单集、合集、音频、文件夹等类型使用不同图标和视觉色调。
- Hero 新增观看状态徽标，已看条目显示“已看”，未看完条目显示当前观看百分比。
- 类型不再混入题材标签行，题材标签只保留 genre 内容，减少重复信息。
- 剧集缩略图新增 `SxEy`/`Ey` 集数角标。
- 剧集缩略图新增进度角标与底部进度条，已看剧集显示完整绿色进度，观看中剧集显示百分比和强调色进度。
- 顺手移除详情页标题的 viewport 字号缩放，改为固定桌面字号和移动端断点字号，避免宽屏下标题比例漂移。

## 验证
- 通过 `npm.cmd run build`。
- 通过修改文件行尾空白检查。
- 通过 `npm.cmd run electron:build`，产物目录为 `release-electron\win-unpacked`。
