# 2026-06-03 17:52 播放器底部控制条收紧

## 背景

用户反馈播放页缺少可用的底部进度条和一系列播放器控件。当前模板已有进度条和控件，但在窄窗口、低高度窗口和嵌入 mpv 场景下，底部控件容易换行挤压，进度条触控面积偏小，视觉上像是不可用或被遮挡。

## 本阶段改动

- 底部控制面板增加最大高度限制，避免小窗口下过度占据视频区域。
- 进度条触控高度从 28px 提升到 34px，轨道从 4px 提升到 5px，滑块从 13px 提升到 16px。
- 控制按钮区域增加稳定最小高度，减少 hover/动态状态导致的布局跳动。
- 小窗口下右侧工具按钮改为横向滚动，不再换行把底部区域撑高。
- 低高度窗口下保留较紧凑但可点的进度条高度。
