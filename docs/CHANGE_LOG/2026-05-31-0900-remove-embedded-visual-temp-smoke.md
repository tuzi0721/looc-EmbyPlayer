# 清理内嵌视觉临时 smoke 脚本

## 背景

上一轮用于排查 Electron 内嵌视觉问题的临时脚本仍留在 `scripts` 目录，并包含真实联调用的测试账号字段。该脚本不属于产品功能或稳定 QA 门禁，不应进入仓库长期状态。

## 改动

- 删除 `scripts/smoke-electron-embedded-visual.mjs`。

## 验证

- 使用 `rg` 检查仓库内是否仍有测试账号名或测试密码明文残留，排除构建产物和依赖目录。

## 结果

仓库内未检出测试账号名或密码明文。后续真实 smoke 只使用临时进程参数或环境变量，不把密码、token 或完整播放 URL 写入仓库文件。
