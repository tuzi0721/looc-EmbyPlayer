# 播放器全屏与小窗口自适应

- **动机**：用户反馈播放器全屏自适应差；上一轮已修正原生全屏入口，本轮继续收紧播放器本身在全屏和最小桌面窗口下的布局。
- **变更**：
  - 播放器根容器补齐 `100dvh` 高度兜底，并用统一边距变量管理顶部、底部控制层。
  - 低高度窗口压缩顶部与底部控制栏，隐藏低优先级按钮和副标题，减少控制层遮挡画面。
  - 弹幕/选集/播放源等弹层在低高度下收窄最大高度，避免弹层越界。
  - 内嵌播放 smoke 新增实际最小桌面窗口断言，覆盖 960×600 下无水平溢出、控制按钮可见和底栏高度上限。
- **验证**：
  - 通过：`node --check scripts\smoke-electron-embedded-local.mjs`
  - 通过：`npm.cmd run build`
  - 通过：`node scripts\smoke-electron-embedded-local.mjs`
  - 通过：`npm.cmd run electron:build`
  - 通过：`git diff --check`
- **结果**：通过；smoke 中 960×620 底栏高度为 86px，960×600 最小窗口顶部/底部控制层、播放按钮和全屏按钮均可见且无水平溢出。当前 Windows 屏幕截图通道仍返回黑帧，脚本保留屏幕截图指标并使用 mpv 自截图彩色视频作为像素 fallback。
