# 2026-05-30 02:45 侧边栏工具入口补齐

## 目标

让已实现的下载管理、通知中心和远程遥控能力在主导航中可直接进入，避免页面与状态逻辑存在但用户找不到入口。

## 变更

- 侧边栏主导航新增“下载”入口，点击进入 `/downloads`，并在有运行/暂停任务时显示数量徽标。
- 侧边栏主导航新增“通知”入口，点击打开现有通知中心抽屉，并在有未读通知时显示未读数量徽标。
- 侧边栏主导航新增“遥控”入口，点击进入 `/remote`。
- 清理侧边栏中已不再渲染的设置分类展开残留状态和辅助函数，让当前导航逻辑更贴近实际 UI。

## 验证

已通过：

```powershell
入口落点检查
设置分类残留检查
行尾空白检查
npm.cmd run build
npm.cmd run electron:build
浏览器冷开 http://127.0.0.1:1420/
```

结果：浏览器中侧边栏可见“下载 / 通知 / 遥控”；点击“下载”后出现“还没有下载任务”，点击“遥控”后出现“目前没有其他在线会话”，点击“通知”后打开“通知中心”，无新增控制台 error。`electron:build` 仍按命令覆盖检查、Vite 构建、Electron builder、打包完整性检查顺序通过。

## 当前状态

- 下载管理、通知中心和远程遥控不再是隐藏页面/隐藏抽屉。
- 下载与通知入口会直接反映当前任务数和未读数。
