# 2026-06-03 17:42 浅色主题可读性收紧

## 背景

用户反馈亮色模式下文字不清、配色怪、通知和界面层级发灰。当前浅色主题大量使用半透明玻璃变量，在 Windows WebView2 禁用 blur 后会失去玻璃分离感，导致文字与背景层级混在一起。

## 本阶段改动

- 收紧浅色主题全局 token：
  - 背景改为更稳定的浅灰工作台色。
  - 主文字/次级文字/弱文字从透明黑改为明确色值，提高可读性。
  - 浅色 accent 从紫色改为蓝青方向，降低单一紫色调带来的怪异感。
- 浅色玻璃层改为更实的白色面板和更明确边框。
- Windows WebView2 禁用 blur 时，浅色侧栏、顶栏、玻璃卡片强制使用实面板背景。
- 浅色 hover/toast 阴影改为低强度蓝灰阴影，避免继续套用暗色的大黑阴影。

## 验证

- `npm.cmd run build` 通过。
- `git diff --check` 通过；仅提示 Windows 工作区后续可能把 LF 转为 CRLF。
