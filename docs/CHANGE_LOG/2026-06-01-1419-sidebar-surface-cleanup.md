# 侧边栏主界面瘦身

- **动机**：用户反馈左下角功能过于杂乱，添加服务器、本地文件、WebDAV、Alist/OpenList 以及最近/收藏快捷入口不应堆在主界面侧边栏里。
- **变更**：
  - 侧边栏底部只保留“设置”入口。
  - 移除侧边栏内的添加服务器弹窗、本地文件选择、本地文件夹选择、WebDAV、Alist/OpenList 和最近/收藏快捷分组。
  - 设置页“文件服务 / 连接器”面板新增本地文件、本地文件夹、WebDAV、Alist/OpenList 入口，继续承接这些功能。
  - 服务器添加入口保留在设置页“媒体库 / 服务器”面板内。
- **验证**：
  - 通过：`npm.cmd run build`
  - 通过：`npm.cmd run check:electron-commands`
  - 通过：`git diff --check`
- **结果**：通过；主界面入口减少，文件服务和服务器维护操作集中到设置页。
