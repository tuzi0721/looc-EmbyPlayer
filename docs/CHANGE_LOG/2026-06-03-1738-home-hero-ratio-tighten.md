# 2026-06-03 17:38 首页巨幕比例收紧

## 背景

用户反馈首页巨幕在小窗口和全屏之间比例不一致，部分窗口下显得过扁或占位空泛，并且下方“继续观看”和媒体库露出不足。

## 本阶段改动

- 将首页巨幕从 `16 / 6` 调整为更接近剧集横幅展示的 `16 / 7`。
- 移除低高度桌面窗口中按高度反推宽度并居中显示的规则，避免出现窄幅居中和左右留空。
- 巨幕高度改为 viewport-aware clamp：
  - 常规桌面保留足够大图展示，但限制最大高度。
  - 低高度桌面、窄窗口、超低高度窗口分别收紧高度，优先给下方行内容留下首屏空间。

## 验证

- `npm.cmd run build` 通过。
- `git diff --check` 通过；仅提示 Windows 工作区后续可能把 LF 转为 CRLF。
