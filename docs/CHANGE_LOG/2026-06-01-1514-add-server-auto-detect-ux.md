# 添加服务器自动识别与表单简化

- **动机**：用户反馈添加服务器缺少账号密码关键入口、端口必须可自定义，且名称、类型和重复 UA 配置让登录流程变得容易失败。
- **变更**：
  - 添加服务器弹窗移除必填名称、类型分段和全局默认 UA 字段，首屏只保留账号与线路。
  - 保存前始终调用真实服务端探测，使用服务端返回的 Emby / Jellyfin 类型与服务器名称；探测失败时不创建伪服务器。
  - 线路地址可直接包含任意端口，也可用独立端口框覆盖；单线路 UA / Headers 保留在高级设置中。
  - 线路区域改为分隔行样式，减少“矩形框套矩形框”的视觉负担。
- **验证**：
  - 通过：`npm.cmd run build`
  - 通过：`npm.cmd run electron:build`
  - 通过：`git diff --check`
  - 未执行：Codex in-app Browser route 当前不可用，无法完成浏览器目检。
- **结果**：通过；添加服务器现在以真实探测结果落库，不再要求用户提前知道服务端名称或手选 Emby/Jellyfin，且不会再在添加流程重复暴露全局 UA。
