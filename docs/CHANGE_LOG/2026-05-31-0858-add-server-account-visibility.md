# 添加服务器账号入口可见性

## 背景

用户指出添加服务器流程里看不到账户用户名和密码选项。复查代码确认账号字段已接入，但 1280x720 预览下账号区位于线路区之后，底部按钮栏会压住或截断输入框，实际体验仍然像“没有账号密码入口”。

## 改动

- `AddServerDialog` 将“账号”区移动到服务器基础信息之后、线路信息之前，让用户名和密码输入在首屏直接可见。
- 弹窗内容区补齐 `min-height: 0`，底部按钮栏设为固定 flex 项并加半透明背景，避免滚动内容视觉上压到操作区下面。

## 验证

- In-app Browser 打开 `http://127.0.0.1:1420/settings?c=servers`，添加服务器弹窗首屏可见“用户名”“密码”和线路端口输入。
- `npm.cmd run build`
- `rg -n "[ \t]+$" src\components\login\AddServerDialog.vue docs\CURRENT_STATE.md`

## 结果

账号用户名、密码、端口和自动识别入口已在添加服务器弹窗首屏同时可见。本阶段没有写入测试账号密码、token 或完整播放 URL。
