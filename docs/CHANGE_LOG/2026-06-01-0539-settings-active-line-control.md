# 设置页当前线路控制

- **时间**：2026-06-01 05:39 (UTC+8)
- **动机**：线路测活已经能驱动 active line，但设置页服务器列表只显示线路健康状态，用户无法直接看出哪条是当前线路，也不能从设置页手动切换。
- **修改文件**：
  - `src/views/SettingsView.vue`：线路元信息新增“当前”标记；启用且非当前的线路显示“设为当前”按钮，调用现有 `serverStore.setActiveLine`。
- **风险**：该入口修改服务器级 active line，不是播放器会话级临时切源；播放中的会话仍按播放器已有切源逻辑处理。
- **回滚**：移除线路元信息中的“当前 / 设为当前”控件和 `setActiveLine` 包装函数。
- **验证步骤**：
  - `npm.cmd run build`
  - in-app Browser 使用上一阶段真实测试账号会话打开 `/settings?c=servers`，确认当前线路显示“当前”，另一条启用线路显示“设为当前”。
  - 点击“设为当前”后，确认标记移动到目标线路，原线路恢复“设为当前”入口。
- **结果**：通过；设置页现在能直接观察和调整服务器 active line，和测活自动切线结果闭环。
