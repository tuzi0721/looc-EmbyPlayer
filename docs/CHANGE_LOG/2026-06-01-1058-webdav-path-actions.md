# WebDAV 当前路径操作

- **动机**：WebDAV 多级目录已经支持面包屑，但常用的当前路径操作仍分散在面包屑和刷新按钮里；深层目录场景需要更直接的回根目录与复制当前路径入口。
- **改动**：
  - `src/views/WebDavView.vue` — 顶部工具栏在深层路径时新增“回到根目录”图标按钮，直接回到当前连接根目录。
  - `src/views/WebDavView.vue` — 顶部工具栏在目录已加载后新增“复制当前路径”图标按钮，复用现有剪贴板工具复制当前目录 URL。
  - `src/views/WebDavView.vue` — 路径复制状态使用短暂按钮提示，并在切换目录或组件卸载时清理定时器。
  - `docs/CURRENT_STATE.md` — 记录 WebDAV 当前路径操作已落地，并更新 Phase 2 文件源能力边界。
- **验证**：
  - `npm.cmd run build`
  - `git diff --check`
  - in-app Browser `/webdav` 页面目检
  - 敏感关键字扫描
- **结果**：通过；`/webdav` 基础页和带路径页均无横向溢出，带路径页可见“上一级”和“回到根目录”入口。浏览器自动填表受虚拟剪贴板限制，未把 mock 连接作为通过项；WebDAV 目录解析继续由本地 smoke 覆盖。
- **风险**：复制动作会把当前目录 URL 放入用户剪贴板，这是用户显式点击后的本机行为；文档与日志不记录真实远端 URL。
